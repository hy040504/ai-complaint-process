# 실행·갱신·복구 절차

현재 운영 기준은 [네이티브 설치·실행·갱신·복구](네이티브_운영.md)다. 설치·적재·API·DB 검사·백업·복구를 해당 문서의 명령으로 수행한다. 현재 실행 구성은 호스트 PostgreSQL과 Python 가상환경·사용자 서비스다.

## 시연 웹·민원 서버의 후속 운영 항목

시연 웹은 게시판·작성 페이지와 민원·답변을 주고받는 서버까지 구현할 계획이며 현재 실행 서비스는 검색 전용이다. 웹·업무 서버의 실제 시작 명령·포트·환경변수·인증·배포 구성은 구현 후 이 문서에 추가한다. 아직 동작하지 않는 명령을 실행 안내로 제공하지 않는다.

구현 시에는 업무 데이터의 민원·답변·상태 이력을 백업·복원하고, RAG 재적재·캐시 정리가 업무 데이터를 삭제하지 않는지 확인한다. 검색·LLM 장애가 발생해도 이미 저장된 민원은 조회·담당자 답변으로 이어져야 하며, AI 재시도가 게시글·답변을 중복 생성하지 않도록 한다. 시연 데이터 초기화와 RAG 지식 갱신은 별도 절차로 기록한다. [웹·민원 서버 계획](../../plan/시연_웹_게시판과_민원_서버_구현계획.md)

CRUD·AI 답변 수정·실시간 모니터의 [통합 상세설계](../../plan/민원_웹_MVP_상세설계와_분야별_작업계획.md)에 맞춰 답변 버전·게시 포인터·작업 실행권·이벤트 커서까지 복구 검증 대상으로 둔다. SSE 연결 수·프록시 버퍼링·타임아웃·재연결과 작업자 중단 후 복구도 구현 시 측정한다. 이벤트 보관 만료 시 스냅샷 재조회, 취소·입력 변경 후 늦은 결과 게시 차단을 확인한다. 이 웹 운영 기능은 미구현이다.
