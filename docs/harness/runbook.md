# 실행·갱신·복구 절차

현재 운영 기준은 [네이티브 설치·실행·갱신·복구](네이티브_운영.md)다. 설치·적재·API·DB 검사·백업·복구를 해당 문서의 명령으로 수행한다. 현재 실행 구성은 호스트 PostgreSQL과 Python 가상환경·사용자 서비스다. 원본 JSON·스키마 SQL·검색 dump는 [데이터 사전](../../rag/origin/README.md), 시연 웹 `complaint_app` DDL은 [업무 스키마](../../src/complaints/schema/complaint_app.sql)를 따른다.

## 시연 웹·민원 서버의 운영 항목

시연 웹 Flask는 `python -m src` 또는 Windows [`웹-시작.cmd`](../../웹-시작.cmd)로 실행한다. 민원·답변은 PostgreSQL `complaint_app` jsonb에 두고 검색 색인 `complaint_rag`와 섞지 않는다. 시작·포트·환경변수는 [서버 안내](../../src/README.md)를 따른다. 검색 dump 복원이 업무 스키마를 지우지 않는지, 업무 백업은 검색 dump와 따로 하는지를 확인한다. SSE·운영 인증·공식 이관은 미구현이라 실행 명령으로 적지 않는다. [웹·민원 서버 계획](../../plan/시연_웹_게시판과_민원_서버_구현계획.md)

CRUD·AI 답변 수정·실시간 모니터의 [통합 상세설계](../../plan/민원_웹_MVP_상세설계와_분야별_작업계획.md)에 맞춰 답변 버전·게시 포인터·작업 실행권·이벤트 커서까지 복구 검증 대상으로 둔다. SSE 연결 수·프록시 버퍼링·타임아웃·재연결과 작업자 중단 후 복구도 구현 시 측정한다. 이벤트 보관 만료 시 스냅샷 재조회, 취소·입력 변경 후 늦은 결과 게시 차단을 확인한다. 이 웹 운영 기능은 미구현이다.
