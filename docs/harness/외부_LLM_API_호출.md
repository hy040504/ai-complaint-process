# 외부 LLM 독립 호출 예제

[프로젝트 소개](../../README.md) · [예제 코드](../../scripts/외부_LLM_예제.py)

외부 모델과 대화하는 독립 Python 예제다. 민원·검색 데이터나 최종 모델 선택과 구별한다. 요청 본문은 코드의 `BODY`에서 수정하며 응답 본문 전체를 출력한다.

저장소 루트의 PowerShell에서 발급받은 토큰을 `PUBLIC_LLM_TOKEN` 환경변수에 설정한 뒤 `python scripts/외부_LLM_예제.py`를 실행한다. 토큰을 코드·문서·Git에 넣지 않는다. 실제 호출에는 외부 서비스 접근이 필요하며 이번 코드 점검에서는 호출하지 않았다.

2026-10-31 점검에서 고정 토큰을 환경변수로 변경했다. 과거 Git 이력에 기록된 인증 값의 재발급은 서비스 소유자가 진행해야 한다. 과거 커밋은 강제로 변경하지 않았다.
