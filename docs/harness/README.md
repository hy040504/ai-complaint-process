# 프로젝트 하네스

[전체 문서](../README.md) · [프로젝트 소개](../../README.md) · [변경 이력](../../CHANGELOG.md)

이 문서 묶음은 사람과 AI 개발 도구가 같은 맥락으로 작업하도록 하는 기본 하네스다. 읽을 자료, 유지할 계약, 실행 방법, 검증 근거, 다음 작업의 완료 조건을 연결한다. 기준일은 **2026-10-24 UTC**다.

문서와 기존 검증 도구를 연결한 단계다. 이 문서를 추가했다고 Jev 판정기나 자동 검증 CI가 실행되는 것은 아니다.

## 확인된 기반과 빈자리

| 영역 | 현재 상태 | 다음 보완 |
| --- | --- | --- |
| 저장소 맥락 | 목적·데이터·코드·작업 규칙 문서화 | 변경과 함께 유지 |
| 검색 실행 | Docker, 적재, 하이브리드 검색 CLI/API 구현 | 처리량·지연 측정 확대 |
| 데이터 검증 | 입력 검증, 원자적 색인 갱신, 원본/DB 대조 구현 | FAQ 현행성·부서 업무분장 검증 기록 |
| 테스트 | 코드·격리 DB 테스트 13개, 검색 회귀 예제 10개 | 한국어 판정용 개발·보류 평가셋 |
| 판정 계약 | 이 문서 묶음에 설계 초안 작성 | 모델 어댑터·출력 검증·예외 경로 구현 |
| 실행 기록 | 적재 메타데이터, 검색 시간, 기존 보고서 | 요청 단위 추적, 설정·정책 버전, 민감정보 제외 |
| 자동화 | 수동 실행 명령 존재 | 가벼운 CI와 별도 모델 평가 작업 |

실행 중인 `/health`에서 FAQ 94건, 사례 5,015건, 부서 127개를 확인했다. 이 중 27개 사례는 현행 담당 부서 검토 대상이며, 127개 부서 모두 공식 업무분장이 미검증이다. 숫자는 이 시점의 스냅샷이며 다음 수집에서도 유지되어야 하는 고정 요구사항은 아니다.

## 문서 유지 기준

| 변경 | 같이 갱신할 문서·근거 |
| --- | --- |
| 데이터 필드·부서 규칙 | 데이터 사전, 데이터 계약, 무결성 검증 결과 |
| 검색 알고리즘·모델·토큰화 | 시스템 구조, RAG README, 해당 평가 결과 |
| API 입력·출력·오류 | 시스템 구조, 호출 예제, 계약 테스트 |
| 판정 모델·프롬프트·임계값 | 판정 정책, 평가 설정, 실행 계획의 결정 기록 |
| 실행 환경·복구 방식 | 운영 절차, Compose, `.env.example` |
| 단계 완료 | 실행 계획, 루트 README의 구현 상태 |

의미 있는 기능·데이터·계약 변경은 [변경 이력](../../CHANGELOG.md)에도 정리한다.

실제 동작은 코드와 재현 가능한 실행 결과로 확인하고, 의도한 정책은 이 문서와 결정 기록으로 확인한다. 불일치가 생기면 어느 쪽을 바꿀지 작업 맥락에 맞게 판단해 함께 정리한다. 과거 테스트 결과에는 실행 당시의 의미를 남기며 새 변경이 검증된 것처럼 재사용하지 않는다.
