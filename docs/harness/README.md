# 프로젝트 하네스

[전체 문서](../README.md) · [프로젝트 소개](../../README.md) · [변경 이력](../../CHANGELOG.md)

이 문서 묶음은 사람과 AI 개발 도구가 같은 맥락으로 작업하도록 하는 기본 하네스다. 읽을 자료, 유지할 계약, 실행 방법, 검증 근거, 다음 작업의 완료 조건을 연결한다. 계획 갱신 기준일은 **2026-10-25 UTC**다.

현재는 검색 계층과 기본 하네스가 있다. 다음 구현은 **Jev 없는 LLM + RAG 기반 판정·FAQ 답변·CLI 챗봇**이다. Jev는 후속 확장이며 LLM 연결과 자동 검증 CI는 아직 구현되지 않았다.

CLI 이후 시연 웹은 민원 게시판·작성 페이지와 민원을 주고받는 서버를 포함한다. 서버에 민원·답변·상태를 저장하는 기능을 계획하며, 기존 RAG 지식과 업무 데이터를 구별한다. 해당 웹·업무 서버도 현재 미구현이다.

2026-10-27에는 실제 목록·CRUD, AI 답변 표시·담당자 수정·실시간 작업 모니터를 추가 구체화했다. [통합 상세설계·분야별 작업계획](../../plan/민원_웹_MVP_상세설계와_분야별_작업계획.md)과 [PDF](../../plan/민원_웹_MVP_상세설계와_분야별_작업계획.pdf)를 후속 구현 기준으로 함께 읽는다. 세부 작업은 UI·백엔드·AI·DB 네 분야의 38개 항목이며 개인별 담당을 배정하지 않는다. 상태·권한·버전·게시·이벤트 계약은 제안이며 기능 구현으로 표시하지 않는다.

## 문서 유지 기준

| 변경 | 같이 갱신할 문서·근거 |
| --- | --- |
| 데이터 필드·부서 규칙 | 데이터 사전, 데이터 계약, 무결성 검증 결과 |
| 검색 알고리즘·모델·토큰화 | 시스템 구조, RAG README, 해당 평가 결과 |
| API 입력·출력·오류 | 시스템 구조, 호출 예제, 계약 테스트 |
| 판정 모델·프롬프트·임계값 | 판정 정책, 평가 설정, 실행 계획의 결정 기록 |
| 실행 환경·복구 방식 | 운영 절차, `scripts/`, 네이티브 서비스 설정 |
| 단계 완료 | 실행 계획, 루트 README의 구현 상태 |

의미 있는 기능·데이터·계약 변경은 [변경 이력](../../CHANGELOG.md)에도 정리한다.

개별 문제의 재현·원인·조치·검증은 [프로젝트 사례](../cases/README.md)에 기록하고 해당 기준 문서로 연결한다. 과거 사례를 읽을 때는 실행 기준일과 미해결 여부를 먼저 확인한다.

실제 동작은 코드와 재현 가능한 실행 결과로 확인하고, 의도한 정책은 이 문서와 결정 기록으로 확인한다. 불일치가 생기면 어느 쪽을 바꿀지 작업 맥락에 맞게 판단해 함께 정리한다. 과거 테스트 결과에는 실행 당시의 의미를 남기며 새 변경이 검증된 것처럼 재사용하지 않는다.
