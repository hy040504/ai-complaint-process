# 사용 가이드

[프로젝트 소개](../../README.md) · [문서 목차](../README.md)

청주톡톡 민원 웹을 **처음 쓰는 분**을 위한 안내서입니다. 개발 지식이 없어도 읽을 수 있게 썼고, 실제 화면에 **빨간 번호**를 붙여 "어디를 누르면 무엇이 되는지" 보여 줍니다.

| 나는 누구인가요? | 읽을 가이드 | 인쇄용 PDF |
| --- | --- | --- |
| **민원을 남기려는 시민** (로그인했든 안 했든) | [민원인 이용 가이드](민원인_이용_가이드.md) | [PDF](민원인_이용_가이드.pdf) |
| **민원을 받아 처리하는 담당자** | [담당자 이용 가이드](담당자_이용_가이드.md) | [PDF](담당자_이용_가이드.pdf) |

## 두 가이드에서 다루는 내용

**민원인 이용 가이드**

1. 첫 화면 보기 → 2. 로그인과 계정 만들기 → 3. 민원 남기기(잘 쓰는 방법, 사진 첨부)
4. AI 민원 도우미에게 물어보기 → 5. 접수한 뒤 화면(수정·철회·삭제) → 6. 내 민원과 민원 게시판
7. 처리 상태와 답변 확인 → 8. 휴대폰에서 쓰기 → 9. 자주 묻는 질문

**담당자 이용 가이드**

1. 로그인 → 2. 첫 화면 보기 → 3. 민원 찾기 → 4. 민원 열어보기(AI 참고 정보 읽는 법)
5. 담당 지정과 부서 배정 → 6. 답변 쓰고 게시하기 → 7. AI 다시 돌리기와 이력
8. 게시판에서 글 내리기 → 9. 통계 보기 → 10. 용어 풀이

## 알아두세요

- 이 서비스는 **시연용**입니다. 청주시 공식 접수와 연결되어 있지 않아요.
- 화면 그림은 시연 데이터로 찍은 것이라 **내용과 숫자는 실제 화면과 다를 수 있습니다.** 버튼과 영역의 위치·이름은 같아요.
- 두 사이트의 주소는 같은 서버의 **시민용(첫 주소)** 과 **담당자용(주소 끝에 `/staff/`)** 입니다.

## 가이드를 고치거나 다시 만들 때 (관리자용)

화면이 바뀌면 그림과 PDF를 다시 만들 수 있습니다.

| 하는 일 | 방법 |
| --- | --- |
| 글 고치기 | 이 폴더의 `.md` 파일을 고칩니다. 그림은 `../assets/guide/`에 있어요. |
| 화면 그림 다시 찍기 | [`scripts/reports/guide/`](../../scripts/reports/guide/README.md)의 안내를 따릅니다. 어떤 화면에 어떤 번호를 붙일지는 `screens.json`에 적혀 있어요. |
| PDF 다시 만들기 | `python scripts/reports/guide/build_guide_pdf.py` (Edge나 Chrome이 설치되어 있어야 합니다) |

> 글에서 설명하는 **번호**는 그림의 번호와 같아야 합니다. 번호를 바꾸면 `screens.json`과 글을 함께 고치세요.
