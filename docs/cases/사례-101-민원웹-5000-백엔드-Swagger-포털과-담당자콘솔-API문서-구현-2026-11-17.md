## 2. 배경·증상과 기대 동작

- 관찰한 사실과 영향:
  - 기존 `:5000`의 `/docs`와 `/swagger`는 `src/complaints/pages.py`에서 `flask-openapi3` 기본 영문 Swagger 페이지(`/openapi/swagger`)로 `302` 리다이렉트만 수행해, 라이트/다크 테마 연동, 담당자/시민 세션 원클릭 전환(보호 경로 `Try it out` 편의), `#/staff`·`#/lab`·`:8007/docs` 이동 링크, 한국어 정책 경계 배너가 부재했습니다.
  - 담당자 콘솔(`ui/src/staff.js` · `app.js`) 내부에는 백엔드 API·Swagger 문서를 열람하거나 검색할 전용 메뉴·화면이 없었습니다.
  - `src/complaints/api.py`의 `jobs`·`answers`·`complaints` 태그 설명이 `CASE-093`/`095` 이전(`"실제 LLM·검색·공식 이관과 연결하지 않는 서버 시뮬레이션"`) 상태로 남아 있었고, `docs/api/청주톡톡_민원_업무_API_Swagger.pdf` 역시 2026-11-05 스냅샷 기준이었습니다.
- 기대 동작:
  - `/docs` 및 `/swagger`에서 외부 CDN 없이 로컬 정적 자산(`/openapi/swagger/*`)만으로 한국어 대화형 Swagger UI를 제공하며, 다크 모드(`minwon-ui-theme`)·실시간 `/api/v1/health` 배지·시연 세션 전환 버튼(`staff`/`citizen`/해제)·`?embed=1` 모드를 지원합니다.
  - 담당자 콘솔에 **`#/staff/api` (`백엔드 API · Swagger`)** 메뉴와 화면을 추가해 라이브 서버 상태, OpenAPI 3.1 요약 카드, 태그/키워드 빠른 색인, 임베드 Swagger UI를 한 곳에서 제공합니다.
  - `#/lab` 단독 응대 검사기 격리(`ui/tests/lab.test.mjs`)와 `/src/*.py` 비노출 보안 경계(`404`)는 그대로 보존합니다.

## 3. 결정 근거와 설계 선택

- 선택지와 결정 이유:
  - 외부 CDN(`unpkg`/`jsdelivr`) 대신 `flask-openapi3`가 이미 내장 서빙하는 `/openapi/swagger/css/swagger-ui.css`, `/openapi/swagger/js/swagger-ui-bundle.js`, `/openapi/swagger/js/swagger-ui-standalone-preset.js`와 라이브 `/openapi/openapi.json`을 직접 재사용해 폐쇄/로컬 환경과 `BaseLayout` 깔끔한 UI를 동시에 확보했습니다.
  - 담당자 콘솔 `#/staff/api`는 순수 OpenAPI 파싱·검색 모듈(`ui/src/api-docs.js`)을 분리해 `node --test`로 HTML/로직 검증을 가능하게 하고, 본문 Swagger UI는 `<iframe src="/swagger?embed=1&theme=...">` + `postMessage({ type: "minwon-theme" })`로 연결해 부모 UI에서 테마를 토글해도 프레임 재로드 없이 즉시 전환됩니다.
  - `app.js`의 1.5초 AI 작업 폴링 `setInterval`이 `#/staff/api`에서 `render()`를 호출해 Swagger UI `iframe`을 새로 고치지 않도록 `currentRoute().path !== "/staff/api"` 가드를 추가했습니다.
  - `/api/v1/health` 실제 JSON 응답이 camelCase(`aiConnected`, `assistSearch`, `assistLlm`)와 `storage: "postgresql"`을 반환함을 라이브 점검으로 확인하고 `swagger_page.py`·`api-docs.js`에서 camelCase 우선 + snake_case 호환으로 통일했습니다.
  - **`Authorize` 빈 모달 원인 및 제거·시각·기능 점검 보완:** `src/app.py`가 `openapi_spec_validator` 검증 통과(`securitySchemes: None` 거부 방지)를 위해 `security_schemes={}`를 두어 Swagger UI가 빈 `Authorize` 버튼을 그리던 문제를 `CheongjuSwaggerPlugin`으로 처리해 클라이언트 스펙에서 빈 `securitySchemes`만 제거했습니다(실제 인증은 `HttpOnly` 세션 쿠키 기반 `POST /api/v1/session` 및 상단 원클릭 세션 버튼 사용). 아울러 태그 이름뿐 아니라 경로·메서드·요약·설명을 통합 검색하는 `opsFilter`, `0.3.0`/`OAS 3.1`/`Expand all`/`No links`/`Controls Accept header.`·방법 배지(`GET`·`POST`·`PUT`·`DELETE`)·OpenAPI 3.1 `json-schema-2020-12` 다크/라이트 대비, `.highlight-code .copy-to-clipboard` 아이콘 보존, `api-docs.js` `cleanDocText()`(`<br/>` 제거) 및 다크 색인 검색창·표 헤더 보정을 적용했습니다.
