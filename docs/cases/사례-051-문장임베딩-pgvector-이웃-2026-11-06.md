## 2. 배경·증상과 기대 동작

- 관찰한 사실과 영향: `문장-임베딩.cmd`는 벡터 숫자만 출력했다. 비슷한 FAQ·사례는 검색 API의 하이브리드 검색에만 있었다.
- 기대 동작 또는 요구사항: 임베딩한 벡터로 pgvector 이웃까지 이어서 보여 준다.
- 확인 근거와 시점: 2026-11-06 사용자 요청 「pgvector로 검색하여 결과가 나오는 기능이 있으면 거기까지 이어서 추가」.

## 3. 재현·확인 방법

- 비교한 기존 동작: 벡터 메타와 384개 숫자만 출력하고 DB에 접속하지 않았다.
- 판단 근거: 검색 엔진의 `dense_search`가 이미 `embedding <=>` 코사인 이웃을 컬렉션별로 조회한다. 문장 스크립트는 그 벡터를 다시 임베딩하지 않고 같은 조회를 쓴다.

## 4. 원인 분석 또는 결정 근거

- 확인된 원인·근거: 문장 스크립트와 검색 엔진이 분리되어 있었고, 벡터 출력 경로에는 DB 조회가 없었다.
- 검토한 선택지와 결정 이유: 하이브리드·재정렬까지 붙이면 기존 `python -m rag search`와 같아진다. 이번 범위는 만든 벡터의 pgvector 이웃만 보여 준다. FAQ와 공개 사례는 한 목록으로 합치지 않는다.
