## 2. 배경·증상과 기대 동작

- 관찰한 사실과 영향: CASE-042가 입출력·캐싱 규칙·가드레일 문서를 만들었으나, LLM이 먼저 읽을 완충지대 요약이 흩어져 있고 실제 프롬프트는 마크다운 인용이며 코드는 짧은 `DECISION_SYSTEM`만 썼다.
- 기대 동작 또는 요구사항: 하네스에 LLM 지침·RAG 다루는 법·응답 법·서버 응답 법이 정리되고, prefix 캐싱용 원문 파일이 존재하며 판정·FAQ 안내가 그 파일을 쓴다.
- 확인 근거와 시점: 2026-11-06 사용자 요청.

## 3. 재현·확인 방법

- 비교한 기존 동작: 시스템 지시는 `constants.py` 문자열, PREFIX-00~04는 `시스템_프롬프트와_프리픽스_캐싱_지침.md` 안 코드 울타리.
- 판단 근거: 캐시 적중을 위해 원문은 파일 상수로 고정하고, 가변 값은 `user` JSON에만 둔다.

## 4. 원인 분석 또는 결정 근거

- 확인된 원인·근거: 개발 운영 문서와 LLM 계약이 같은 README 표에 섞여 있었다.
- 검토한 선택지와 결정 이유: 원본은 `docs/harness/prompts/*.txt`, 런타임은 `src/assist/prompts.py`가 기동 시 읽는다. 마크다운에 전문을 복제하지 않는다.
