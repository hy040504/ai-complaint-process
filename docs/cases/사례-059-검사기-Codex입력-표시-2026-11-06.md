## 2. 배경·증상과 기대 동작

- 관찰한 사실과 영향: 검사기는 시민 안내·검색 히트만 보여 주어 Codex stdin 사용자 JSON을 화면에서 확인할 수 없었다.
- 기대 동작: 결과 화면에 `assist.codex` 목록을 보여 준다. 1차 호출은 PREFIX-00+01과 `query`·`district`·FAQ·사례·부서 후보다. FAQ 안내면 PREFIX-00+02 호출이 이어진다.
- 확인 근거: 2026-11-06 사용자 요청.

## 3. 재현·확인 방법

- 재현 환경: 검사기 웹에서 민원을 보낸 뒤 「Codex에 보낸 데이터」 절을 본다.
- PREFIX 전문은 민원마다 바뀌지 않으므로 응답에 넣지 않고 `system` 표시만 둔다.

## 4. 원인 분석 또는 결정 근거

- Codex는 검색을 다시 하지 않고, 코드가 만든 후보 JSON을 사용자 본문으로 받는다. 그 JSON을 응답 계약에 실어 검사기가 그대로 보여 준다.
