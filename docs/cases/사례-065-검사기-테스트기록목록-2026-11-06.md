## 2. 배경·증상과 기대 동작

- 관찰한 사실과 영향: 검사기는 한 번 보낸 결과만 본문에 보여 주고, 이전 검사는 사라졌다.
- 기대 동작 또는 요구사항: 민원을 보낸 뒤 오른쪽 목록에서 골라 당시 결과를 다시 본다. 테스트 자료 확인용이며 모델을 다시 부르지 않는다.
- 확인 근거와 시점: 2026-11-06 사용자 요청.

## 3. 재현·확인 방법

- 재현 환경·선행 조건: `http://127.0.0.1:5010/`
- 개인정보를 제거한 입력, 단계, 실제 결과:
  - 민원을 보내면 오른쪽에 제목·갈래·시각이 생긴다.
  - 항목을 고르면 응대 결과·JSON이 바뀌고, 기록에서 다시 본다는 안내가 보인다.
  - `모두 지우기`는 이 브라우저 기록만 지운다.
- 설계 근거: 업무 민원과 섞지 않으려고 서버 저장을 두지 않는다.

## 4. 원인 분석 또는 결정 근거

- 확인된 원인·근거: 결과 화면이 마지막 응답 하나였다.
- 아직 확인하지 않은 가설: 다른 브라우저·시크릿 창은 기록이 없다.
- 결정: `localStorage` 키 `lab-test-runs`. 선택 시 재호출 없음.
