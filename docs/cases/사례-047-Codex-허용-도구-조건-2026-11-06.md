## 2. 배경·증상과 기대 동작

- 관찰한 사실과 영향: Codex 래퍼와 `PREFIX-00`이 도구·파일 접근을 전면 금지했다. 이 문장은 두 기획 분석서가 아니라 구현에서 넣은 것이다.
- 기대 동작 또는 요구사항: 개발자가 그 호출에 허용한 도구만 쓰고, 그 밖은 쓰지 않는다.
- 확인 근거와 시점: 2026-11-06 사용자 요청.

## 3. 재현·확인 방법

- 재현 환경·선행 조건: 저장소의 Codex 호출 문구.
- 개인정보를 제거한 입력, 단계, 실제 결과: 변경 전 래퍼는 "도구를 사용하거나 파일을 읽거나 수정하지 마세요"였다.
- 버그가 아닌 설계·개선 기록이라면 비교한 기존 동작과 판단 근거: 전면 금지 대신 허용 목록으로 바꾼다. 목록이 비어 있으면 도구를 쓰지 않는다.

## 4. 원인 분석 또는 결정 근거

- 확인된 원인·근거: 기획서는 LLM을 근거 기반 초안에 두고 인젝션을 막으라고 적는다. 도구 전면 금지는 그 문장을 구현이 좁혀 쓴 것이다.
- 아직 확인하지 않은 가설: 없음.
- 검토한 선택지와 결정 이유: 샌드박스와 빈 작업 디렉터리는 유지한다. 허용 도구를 실제로 붙이는 작업은 이번 범위가 아니다.
