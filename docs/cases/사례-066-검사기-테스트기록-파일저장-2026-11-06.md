## 2. 배경·증상과 기대 동작

- 관찰한 사실과 영향: CASE-065 목록은 `localStorage`라 브라우저를 바꾸거나 지으면 기록이 사라졌다.

- 확인 근거와 시점: 2026-11-06 사용자 요청.

## 3. 재현·확인 방법

- 재현 환경·선행 조건: `http://127.0.0.1:5010/`, 폴더 `.rag-cache/lab-runs`
- 개인정보를 제거한 입력, 단계, 실제 결과:
  - `POST /api/v1/lab/complaints` 성공 시 `{id}.json`이 생긴다.
  - `GET /api/v1/lab/runs`로 목록, `GET /api/v1/lab/runs/<id>`로 본문.
  - `DELETE /api/v1/lab/runs`는 기록 JSON만 지운다.
- 설계 근거: 업무 `complaint_app`과 RAG 원본에 섞지 않는다. Git 제외는 민원 원문 보호다.

## 4. 원인 분석 또는 결정 근거

- 확인된 원인·근거: 브라우저 저장만으로는 검사 자료가 남지 않는다.
- 아직 확인하지 않은 가설: 운영 공유 디스크·백업 정책.
- 결정: `.rag-cache/lab-runs`. 경로는 `LAB_RUNS_DIR`로 바꿀 수 있다.
