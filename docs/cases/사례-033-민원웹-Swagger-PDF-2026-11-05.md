## 2. 배경·증상과 기대 동작

- 관찰한 사실과 영향: 시연 웹 Swagger는 `http://127.0.0.1:5000/docs`에서 동작하나, 서버 없이 배포·보고할 인쇄본이 없었다.
- 기대 동작 또는 요구사항: 그 Swagger 페이지를 PDF로 `docs/`에 만든다.
- 확인 근거와 시점: 2026-11-05 사용자 요청.

## 3. 재현·확인 방법

- 비교한 기존 동작: 설계 PDF는 `docs/tools/export_design_pdf.py`로 Markdown을 인쇄한다. Swagger는 flask-openapi3가 모델에서 OpenAPI JSON을 만든다.
- 판단 근거: 검색 FastAPI `:8007/docs`가 아니라 민원 웹 Flask `/docs`가 대상이다.

## 4. 원인 분석 또는 결정 근거

- 확인된 원인·근거: 실행 중 UI는 JS로 접혀 있어 인쇄하면 엔드포인트가 비어 보인다.
- 검토한 선택지와 결정 이유: 메모리 저장소 앱의 `/openapi/openapi.json`을 읽어 Swagger 색 구분·태그·모델로 펼친 HTML을 Chrome 인쇄한다. 서버 기동·PostgreSQL이 필요 없다.
