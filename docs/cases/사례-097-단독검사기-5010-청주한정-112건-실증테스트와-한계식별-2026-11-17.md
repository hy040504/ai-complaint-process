## 2. 실증 테스트 설계 (`:5010` 직접 호출 · 112건)

- **구성:** 기본 5축 **100건**(`codex_cli` 90건 + `exaone_api` 교차 10건) + 청주 외곽 읍·면(미원·현도·강내·북이), 명소(청남대·육거리시장·고인쇄박물관·수암골·문암생태공원), 청주시 내 타기관·민간 소관(아파트 관리비 형사고발·경부고속도로 청주IC·가상 구청 "중구청") **추가 12건** = **총 112건** (타 지자체 대조군 `C09` 대전 유성구·`C20` 세종 조치원읍 2건 제외 시 **청주 한정 110건**).
- **기록 보존:** 실행 결과는 `.rag-cache/lab-runs`에 JSON으로 저장되었으며(총 128개 파일, 업무 PostgreSQL `complaint_app`에는 기록하지 않음), 모든 자동 판정 후 답변·초안·순화·장소 JSON을 직접 전수 대조했습니다.

## 4. 이번 실증에서 식별한 코드 한계 3건 (후속 패치 대상)

1. **`SANITIZE_HINTS` 정적 부분일치 오탐 및 우회·조롱 미탐 ([`src/assist/followup.py`](../../src/assist/followup.py)):**
   - **오탐 (`B02`·`B14`·`E17`):** `"꺼져"` 문자열이 `"보도블록이 움푹 꺼져서"`, `"가로등이 꺼져"`에 걸려 정상 시설물 민원에서 불필요한 `PREFIX-04` 순화 호출이 발생했습니다(`B14`는 LLM이 `riskSignals: []` 반환).
   - **미탐 (`D09`~`D13`, `D15`~`D18`, `D20`, `F12`):** 초성(`ㅅㅂ`, `ㅂㅅ`), 공백 삽입(`시 발`), 일반 비속어(`존나`, `지랄`, `개같네`, `대가리`), 보복 예고(`책상 다 뒤엎고`, `가만 안 둔다`), 비꼬는 조롱 민원이 정적 12단어 목록에 없어 `sanitize`가 작동하지 않았습니다.
2. **동·읍·면 뒤 숫자 결합 시 지명 정규식 누락 (`B17`, [`src/assist/district.py`](../../src/assist/district.py)):**
   - `"봉명동1349번지근처..."`처럼 지명 뒤에 공백 없이 숫자(`1349`)가 붙으면 `_AREA_PATTERN`의 뒤쪽 경계 `(?=\s|[^\w가-힣]|$)`에서 숫자가 `\w`로 취급되어 매칭에 실패해 `effectiveDistrict=None`이 됩니다.
3. **네이버 장소 추적 일반 명사 오매칭 및 단독 랜드마크 컷오프 (`B06`·`B12`·`C15`, [`src/llm/place_tool.py`](../../src/llm/place_tool.py)):**
   - `"청주국제공항 진입로 부근..."`(`B06`)에서 `extract_place_candidates()`가 2단어 조합 5개(`_MAX_FALLBACK_CANDIDATES = 5`)만 먼저 잘라 시도해 단독 명사 `"청주국제공항"`이 누락되었습니다.
   - `B12`(`"(지역 미기재)"`)의 `"지역"`이 `한국방송통신대학교 충북지역대학`과, `C15`의 `"공식 접수"`가 `코웨이 청주코웨이렌탈공식접수센터`와 `is_place_relevant()` 부분 일치로 잘못 매칭되었습니다.
