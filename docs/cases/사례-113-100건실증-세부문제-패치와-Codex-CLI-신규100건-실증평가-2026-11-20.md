## 1. 배경 및 발견된 문제

`CASE-109` 100건 재검증([`lab-5010-eval-100-20261120.json`](../../rag/reports/lab-5010-eval-100-20261120.json), `98/100, 98.0%`) 원자료 전수 점검에서 아래 세부 문제들이 확인되었습니다.

1. **`A24` (명확한 불가/제외 FAQ 과도 보류 — 1건 미통과):** `"주말에 시청 무인민원발급기에서 인감증명서 발급이 가능한가요?"` 질의에서 관련 FAQ 3건(`1312772`·`1313468`·`1313678`)을 정확히 찾고도 본문에 `"주말 운영시간"`이 없다는 이유로 `human_handoff / condition_unclear`로 보수 보류했습니다.
2. **`N32` · `A15` (후속 JSON 파싱 쉼표 누락 및 Codex 오류 장문 덤프):**
   - `N32`에서 `PREFIX-03` 담당자 초안 생성 시 모델이 JSON 쉼표 하나를 누락(`Expecting ',' delimiter: line 1 column 786`)해 초안이 `None`으로 탈락했습니다.
   - `A15`에서 Codex CLI 호출이 한도에 걸렸을 때 `stderr` 전체(`24KB`, 시스템 프롬프트 원문 `[시스템 지시]` 포함)가 그대로 `policy_failures`에 기록되었습니다.
3. **`N18` 및 Codex `staff_draft` 지연 · 미고정 공급자 폴백:**
   - `N18`(수암골전망대)에서 `exaone_api` `decision` 단계(`high` 추론 + `max_tokens=16384`)가 180초 타임아웃으로 `llm_unavailable`을 반환했습니다.
   - `codex_cli`의 `PREFIX-03`(`staff_draft`) 단계는 이미 검색 결과를 입력 JSON에 모두 받는데도 불필요한 MCP 서버 기동이 유지되어 비FAQ 호출마다 3~5초와 토큰이 추가 소모되었습니다.
4. **신규 100건 실측 사후 감사에서 추가 포착된 `K12` 일반명사 노이즈:** `"출생신고 부모 본인 방문..."` 문항에서 `"부모"`가 불용어 목록에 없어 네이버 지도 조회 시 `부모사랑 재가장기요양기관`(`청원구`)이 부가 배지로 매칭되었습니다.

### 2.2 경량 JSON 복구 · 1회 형식 재시도 · Codex 핵심 오류 추출 (`src/llm/complete.py`, `src/assist/pipeline.py`)

- **`_repair_json_text()` (`complete.py`):** `parse_json_object()` 1차 파싱 실패 시 문자열 내부 미이스케이프 줄바꿈/탭, 닫는 괄호 직전 후행 쉼표, 다음 키(`"key":`) 직전 쉼표 누락을 안전하게 보정한 뒤 재파싱합니다.
- **`PREFIX-03`/`PREFIX-04` JSON 1회 자동 재시도 (`pipeline.py`):** 환경 LLM 실행(`llm_fn is USE_ENV_LLM`)에서 초안·순화 파싱 또는 스키마 검증이 실패하면 짧은 형식 재확인 문구(`_JSON_RETRY_REMINDER`)를 붙여 1회 재시도합니다.
- **`_extract_codex_error()` (`complete.py`):** Codex CLI 실패 시 `ERROR:` 핵심 문장만 최대 240자로 발췌해 `[시스템 지시]` 등 20KB 프롬프트 전문이 `policy_failures`나 로그에 노출되지 않도록 차단했습니다.

### 2.3 EXAONE 타임아웃 완화 · Codex `staff_draft` MCP 생략 · 미고정 자동 폴백 (`src/llm/settings.py`, `complete.py`, `pipeline.py`, `.env.example`)

- **EXAONE `decision` 상한 및 1회 `low` 재시도:** `settings_for_role()`에서 EXAONE `decision` 역할 `max_tokens` 기본 상한을 `8192`(`EXAONE_DECISION_MAX_TOKENS`)로 낮추고, `complete_exaone_result()`가 `"요청 시간 초과"`를 만나면(`effort != "low"`) `reasoning_effort="low"`·`max_tokens<=4096`으로 1회 자동 재시도합니다.
- **Codex `staff_draft` 불필요 MCP 기동 생략:** `settings_for_role()`의 `codex_cli` `_disable_mcp="1"` 대상을 `("faq_answer", "sanitize", "staff_draft")`로 확장하고 `_record_codex_call`의 `disable_tools` 플래그를 실제 공급자(`codex_cli`)와 일치시켰습니다.
- **미고정 호출 1회 투명 폴백:** `provider is None`(명시 고정하지 않은 `.env` 기본 호출)이 한도/타임아웃(`_is_provider_limit_error`)으로 실패하고 `COMPLAINT_LLM_AUTO_FALLBACK`이 활성(`기본 1`)이면 다른 준비된 공급자(`fallback_provider_settings`)로 1회 전환합니다. **사용자가 `provider="codex_cli"` 등으로 명시 고정한 호출은 절대 다른 엔진으로 몰래 바꾸지 않습니다.**

### 2.4 시설물·가족·신고 일반명사 불용어 보강 (`src/llm/place_tool.py`, `src/tests/test_place_tool.py`)
