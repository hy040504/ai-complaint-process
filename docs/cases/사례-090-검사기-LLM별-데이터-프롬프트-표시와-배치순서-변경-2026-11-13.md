## 2. 배경·증상과 기대 동작

- 관찰한 사실과 영향:
  - K-EXAONE 2.5(`exaone_api`)와 OpenAI GPT API(`openai_api`)를 선택한 경우에도 결과 화면 하단 제목과 설명이 `Codex에 보낸 프롬프트`·`Codex에 보낸 데이터`로 고정되어 있어, 어느 모델로 전달된 데이터인지 혼동이 생겼습니다.
  - 또한 기본 설정(`.env`) 버튼으로 호출할 때 프론트엔드는 `payload.provider`가 비어 있어 실제 `.env`가 어느 공급자(`exaone_api`/`codex_cli`/`openai_api`)로 해석됐는지 결과 화면에서 바로 알기 어려웠습니다.
  - 배치 순서도 `프롬프트` 블록이 위, `데이터 JSON` 블록이 아래에 있어 구조화 입력 JSON을 먼저 확인하기 불편했습니다.
- 기대 동작:
  1. 사용한 LLM에 따라 데이터·프롬프트 영역 제목·배지 칩·안내 문구·복사 버튼 `aria-label`·호출 카드 헤더가 **엑사온 API (K-EXAONE 2.5)**, **Codex CLI**, **GPT API (GPT-6 Luna)** 중 무엇인지 명확하게 표시됩니다(`.env` 기본 설정 포함).
  2. 결과 상세 영역에서 **보낸 데이터(JSON)** 영역이 위(`#llm-data-block`), **보낸 프롬프트** 영역이 아래(`#llm-prompt-block`)로 배치됩니다.

## 3. 원인 분석과 설계

- **백엔드 해석 메타데이터 전달 (`AssistResponse.llm_provider` / `llm_model`, `ProviderStatus.resolved_provider`):**
  - [pipeline.py](../../src/assist/pipeline.py)에 `_resolve_bound_settings()`를 분리해 `resolve_chat()`과 `iter_assist()`가 같은 해석 결과를 공유하도록 정리하고, `build_result()`·`AssistResponse`([models.py](../../src/complaints/models.py))에 선택/해석된 `llm_provider`·`llm_model`(`llmProvider`/`llmModel`)을 추가했습니다.
  - [settings.py](../../src/llm/settings.py) `provider_availability_map()`과 [lab_web/models.py](../../src/lab_web/models.py) `ProviderStatus`에도 `resolved_provider`를 포함해 `/api/v1/lab/fields` 단계부터 `.env` 기본 공급자를 알 수 있게 했습니다.
- **프론트엔드 배치 변경 및 엔진별 동적 표시:**
  - [index.html](../../src/lab_web/static/index.html)에서 `#llm-data-block`(`#codex-json`)을 위로, `#llm-prompt-block`(`#codex-prompts`)를 아래로 배치하고 제목 옆 `.engine-chip` 자리를 추가했습니다.
  - [app.js](../../src/lab_web/static/app.js)의 `resolveLlmSectionMeta()`와 `showResult()`가 `assist.llmProvider` → 요청 `provider` → `.env` 기본 해석 순으로 실제 엔진을 판정해 `엑사온 API (K-EXAONE 2.5)에 보낸 데이터/프롬프트`, `Codex CLI에 보낸 데이터/프롬프트`, `GPT API (GPT-6 Luna)에 보낸 데이터/프롬프트` 제목, 색상 배지 칩(`.engine-chip--exaone_api`/`codex_cli`/`openai_api`), 호출 카드 제목(`1. 1차 판정 · 엑사온 API · ...`)을 채웁니다.
  - 기존 API·테스트와의 호환을 위해 `assist.codex[].prompt` 원문 포맷(`format_codex_stdin`)과 DOM ID(`#codex-json`, `#codex-prompts`, `#codex-note`, `#codex-prompt-note`)는 그대로 유지했습니다.
