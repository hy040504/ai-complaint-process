## 2. 확인된 문제와 근거

[데이터 계약](../harness/data-contracts.md#2026-10-24-기준-품질-현황)에 기록된 FAQ 94건의 등록일은 2023-03-30~2023-04-22입니다. 최근 수집일은 원문을 가져온 날짜이므로 대상·서류·기간·접수처·전화번호가 현재도 유효한지 별도 확인해야 합니다. 개별 안내의 오류 여부와 현행성은 아직 미확인입니다.

부서 표기 정규화는 이미 적용했으나 정책 조건과 연락처 전체를 확인한 작업은 아닙니다. 현행성 확인 없이 자동 답변을 허용하면 오래된 조건을 안내할 가능성이 있습니다.

## 3. 현재 대응과 확인 범위

현재는 검색 결과로 FAQ 원문과 출처를 반환하며 LLM 답변은 미구현입니다. 원문 보존은 [source-preservation.json](../../rag/reports/source-preservation.json)에 기록되어 있습니다. 이 보존 검증은 안내 내용의 현행성 검증과 다른 확인입니다.

대상·접수 조건·주의사항은 통째로 보존합니다. 앞으로의 답변 허용 여부는 [판정 정책](../harness/decision-policy.md)과 [LLM + RAG 구현계획](../../plan/언어모델과_검색증강생성_우선_구현계획.md)에 따라 근거와 승인 범위를 확인해야 합니다.

## 4. 후속 조치와 완료 조건

1. 시연할 FAQ를 선정하고 현행 공식 안내·접수처와 원문을 대조합니다.
2. 항목별 `source_id`, 원문 해시, 확인 항목·출처·일자·상태를 기록하는 승인 방식을 구현합니다. 해당 필드는 현재 JSON·DB의 구현 완료 항목이 아닙니다.
3. 승인된 범위만 답변에 사용하고, 조건·예외·현행성 근거가 부족하면 담당자 검토로 연결합니다.
4. 원문이 바뀌면 재확인하고, 조건 누락·출처 불일치·미승인 안내의 답변 차단을 평가합니다.

선택한 FAQ 범위의 현행성 근거와 변경 시 재검토 경로가 마련되고, 미승인 내용을 자동 안내하지 않는 동작을 확인해야 완료로 기록합니다. 일부만 확인했으면 확인 범위와 남은 항목을 나눠 기록합니다.

2026-10-25에는 기존 문서·보존 보고서를 대조해 과제로 등록했습니다. 공식 정책·연락처 재확인과 LLM 답변 검증은 미실행입니다. 수정 시 이전 원문과 승인 기록을 보관하며 문제가 확인된 항목은 답변 허용 범위에서 제외합니다. 실행 순서는 [MVP 실행 계획](../../plan/harness-roadmap.md)을 따릅니다.
