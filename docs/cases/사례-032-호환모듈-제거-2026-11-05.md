## 2. 배경·증상과 기대 동작

- 관찰한 사실과 영향: `src/api.py` 등 9개가 `src.complaints`를 다시보내기만 해서 루트와 `complaints/`가 같은 이름 두 벌처럼 보였다.
- 기대 동작 또는 요구사항: 역할 폴더는 네 패키지로 두고, 호환 모듈은 없앤다. `app.py`는 조립 진입점으로 루트에 남긴다.
- 확인 근거와 시점: 2026-11-05 사용자 요청.

## 3. 재현·확인 방법

- 비교한 기존 동작: 테스트가 `from src.config import Settings`처럼 옛 경로를 썼다. 외부 코드의 해당 import는 테스트뿐이었다.
- 판단 근거: 호환 모듈을 다른 폴더로 옮기면 이름이 또 겹친다.

## 4. 원인 분석 또는 결정 근거

- 확인된 원인·근거: CASE-026이 기존 import를 깨지 않으려고 루트에 재내보내기를 남겼다.
- 검토한 선택지와 결정 이유: `src/compat/`로 모으지 않고 삭제한다.
