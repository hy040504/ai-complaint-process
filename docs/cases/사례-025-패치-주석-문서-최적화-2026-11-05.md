## 2. 배경과 기대 동작

- GPT-6 Luna 공급자와 Windows 시작 스크립트 패치에 한 줄 docstring만 있거나, Returns 설명이 예전 토큰 전용 계약과 어긋난 함수가 있었다.
- 응대 파이프라인이 `llm_configured()`를 같은 요청에서 여러 번 호출하고, `.env`를 호출마다 다시 읽었다. 공백 `OPENAI_API_KEY`도 설정됨으로 볼 수 있었다.
- 루트 README의 단계 날짜와 저장소 트리가 Flask·검사기·`웹-시작.cmd`를 충분히 보여 주지 않았다.
