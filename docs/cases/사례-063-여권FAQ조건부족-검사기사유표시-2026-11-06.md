## 2. 배경·증상과 기대 동작

- 관찰한 사실과 영향: 초안 평가 10건 중 `FAQ_성인여권`만 `human_handoff`/`insufficient_evidence`로 `faq_answer` 기대와 달랐다. 검색 1위는 `source_id` 1312277 「성인 여권 발급」이다.
- 기대 동작 또는 요구사항: FAQ 본문에 필요 서류가 없으면 서류를 지어 안내하지 않고 담당자 검토로 보낸다. 검토한 FAQ는 근거에 남긴다. 검사기는 처리 사유를 보여 준다.
- 확인 근거와 시점: 2026-11-06 사용자 요청 「검사기 남은 것부터」.

## 3. 재현·확인 방법

- 재현 환경·선행 조건: 검색 API `:8007`, `.venv-web`.
- 개인정보를 제거한 입력, 단계, 실제 결과:
  - 질의 「성인이 여권을 처음 발급받으려면 어떤 서류를 준비해야 하나요?」
  - FAQ 본문: 수수료·접수 시간·접수처. `서류`·`신분증` 없음.
  - PREFIX-01 보강 전: `human_handoff` / `insufficient_evidence` / `evidence_refs` 빈 배열.
  - 보강 후: `human_handoff` / `condition_unclear` / 근거 `faq/1312277`. `automatic_transfer` 거짓.
- 버그가 아닌 설계·개선 기록이라면 비교한 기존 동작과 판단 근거: 검색 Hit@5 통과를 FAQ 자동 안내 정답으로 쓰지 않는다.

## 4. 원인 분석 또는 결정 근거

- 확인된 원인·근거: 질문이 필요 서류를 묻는데 FAQ에 목록이 없다. 모델이 안내를 거부한 것은 정책과 맞다. 초안 평가가 `faq_answer`만 기대한 것이 잘못된 라벨이다.
- 아직 확인하지 않은 가설: 원문 사이트에 서류 안내가 있고 수집본만 빠진 경우. CASE-004 현행성 과제와 연결한다.
- 검토한 선택지와 결정 이유: 서류를 생성해 `faq_answer`로 맞추지 않는다. `condition_unclear`와 FAQ 근거 보존을 지시한다.
