## 2. 배경과 요구사항

- **배경:**
  - LG AI연구원의 `K-EXAONE 2.5`(`k-exaone_v2.5`)는 에이전틱 사고(Thinking)가 상시 활성화되어 답변 생성 전에 심층 추론 과정을 수행합니다.
  - 공식 문서([docs.exaone.ai](https://docs.exaone.ai))에 따르면 `max_tokens` 제한에는 **최종 답변 토큰뿐만 아니라 내부 추론 토큰(`reasoning_tokens`)까지 합산**되어 계산됩니다.
  - 기존 초기 연동 시 `max_tokens`가 2,048로 하드코딩되어 있어, 복잡한 민원 판정 및 초안 작성 시 추론 도중 토큰이 소진되어 응답이 중단되거나 JSON 파싱이 실패할 위험이 있었습니다.
  - 또한 추론의 깊이를 제어하는 `reasoning_effort`(`low`, `high`, `max`)를 사용자가 환경설정(`.env`)에서 직관적으로 변경할 수 있어야 했습니다.
- **요구사항:**
  - `max_tokens`를 최대 수준(기본 16,384, 컨텍스트 512K 지원)으로 상향하고 환경변수로 조절 가능하도록 구현.
  - `.env`에 `EXAONE_REASONING_EFFORT` 키를 새로 만들어 공식 문서 스펙에 맞게 추론 강도를 연동.
  - 정형 JSON 구조 출력 안정성과 에이전틱 추론 품질을 감안하여 `temperature=0.7`, `top_p=0.95` 등 프로젝트 최적 파라미터 적용.
  - 마크다운 코드블록(````json ... ````) 출력에 대한 방어 파싱 및 `reasoning_tokens` 사용량 집계 지원.

## 3. 조치 내용

1. **설정 관리자 및 환경변수 키 등록 (`src/llm/settings.py`):**
   - `_LLM_ENV_KEYS`에 `EXAONE_REASONING_EFFORT`, `EXAONE_MAX_TOKENS`, `EXAONE_TEMPERATURE`, `EXAONE_TOP_P` 등록.
   - 기본 상수 정의:
     - `DEFAULT_EXAONE_REASONING_EFFORT = "max"` (공식 기본값)
     - `DEFAULT_EXAONE_MAX_TOKENS = 16384` (내부 추론 + 답변 토큰을 넉넉히 수용)
     - `DEFAULT_EXAONE_TEMPERATURE = 0.7`
     - `DEFAULT_EXAONE_TOP_P = 0.95`
   - `settings_for_provider("exaone_api")`에서 환경변수 우선 적용 로직 구현.
2. **완성 요청 로직 파라미터 반영 및 방어 파싱 (`src/llm/complete.py`):**
   - `complete_exaone_result`:
     - 페이로드에 `max_tokens`(16384), `reasoning_effort`(`low`/`high`/`max`), `temperature`, `top_p` 반영.
     - 응답 텍스트에 마크다운 코드블록(` ```json ... ``` `)이 포함된 경우 순수 JSON 본문만 추출하는 방어 로직 추가.
     - `usage_from_openai`: `reasoning_tokens` (또는 `completion_tokens_details.reasoning_tokens`) 파싱 지원.
3. **스키마 및 모델 보강 (`src/complaints/models.py`):**
   - `LlmUsage` 모델에 `reasoning_tokens: int | None = None` 필드 추가.
4. **환경 설정 템플릿 최신화 (`.env`, `.env.example`, `README.md`):**
   - `.env.example` 및 `.env`에 `EXAONE_REASONING_EFFORT=max`, `EXAONE_MAX_TOKENS=16384`, `EXAONE_TEMPERATURE=0.7`, `EXAONE_TOP_P=0.95` 템플릿 안내 추가.
   - 메인 `README.md`에 파라미터 가이드 표 명시.
5. **단위 테스트 보강 (`src/tests/test_llm_env.py`):**
   - 모의 호출에서 `max_tokens == 16384`, `reasoning_effort == "high"`, `temperature == 0.7`, `top_p == 0.95` 및 `reasoning_tokens` 파싱 검증.
