## 2. 배경·증상과 기대 동작

- 관찰한 사실과 영향: CASE-064~066은 평가셋 확대와 검사기 오른쪽 목록·파일 저장에 집중했다. 루트 README 구현 표는 초안 평가 9/10을 남겼고, 검사기 칸은 민원 저장 없음만 적었다. `list_runs`와 `load_run`이 JSON 읽기를 각각 했고, 평가 실행기는 문항을 두 번 골랐다.
- 기대 동작 또는 요구사항: 한국어 Google 형식 docstring, 패치와 같은 현재 문서, 기록 JSON 읽기·목록 칸을 한 경로에서 만든다.
- 확인 근거와 시점: 2026-11-07 사용자 요청 「주석 점검, readme/docs 업데이트, readme 디자인 개선, 코드 최적화, 깃헙 업로드」.

## 3. 재현·확인 방법

- 비교한 기존 동작: `save_run` 뒤 `LabRunSummary` 칸을 손으로 채웠다. `Path(app.config["LAB_RUNS_DIR"])`를 라우트마다 반복했다. `응대_평가.py`는 `--only`/`--missing`에 `select_items`를 다시 호출했다. README 현재 단계는 2026-11-06·9/10이었다.
- 판단 근거: `_read_json`·`run_summary`·`_runs_dir`로 경로를 모은다. 초안 평가 개발 26/26과 `.rag-cache/lab-runs`를 현재 상태로 적는다.

## 4. 원인 분석 또는 결정 근거

- 확인된 원인·근거: CASE-064~066은 동작 수정에 집중했고 주석·현재 문서·소규모 최적화를 이 작업으로 넘겼다.
- 검토한 선택지와 결정 이유: 민원 CRUD LLM을 연결하지 않는다. 보류 3건을 프롬프트 조정에 쓰지 않는다. `.env`와 벡터 dump는 Git에 넣지 않는다.
