## 2. 배경·증상과 기대 동작

- 관찰한 사실과 영향: 기본 임베딩은 `intfloat/multilingual-e5-small`이었다. 한국어 검색용 미세조정 모델이 별도로 있다.
- 기대 동작 또는 요구사항: `https://huggingface.co/dragonkue/multilingual-e5-small-ko`를 받아 검색에 쓴다.
- 확인 근거와 시점: 2026-11-06 사용자 요청.

## 3. 재현·확인 방법

- 비교한 기존 동작: 프로필 `e5-small`, 리비전 `960310a7742a4e0a250dd720466bed84fee8caac`, 이 호스트 색인도 그 서명.
- 판단 근거: 모델 카드는 384차원, 최대 512토큰, `query:`/`passage:` 접두, 코사인이다. 차원이 같아도 가중치가 다르므로 색인을 다시 만든다.

## 4. 원인 분석 또는 결정 근거

- 확인된 원인·근거: Hugging Face 모델 SHA는 `bba4cb8e3299d445c04f62bf62e2b26461d03715`(2025-10-16).
- 검토한 선택지와 결정 이유: 기본 프로필 이름을 `e5-small-ko`로 두고, 이전 intfloat 프로필 `e5-small`과 `bge-m3`는 남긴다. 카드에 있는 v2 모델은 요청하지 않아 쓰지 않는다.
