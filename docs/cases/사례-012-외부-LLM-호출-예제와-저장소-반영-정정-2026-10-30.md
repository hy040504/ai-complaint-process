## 2. 배경·증상과 기대 동작

외부 모델 서버 공개 요청으로 별도 LLMmanager 저장소를 작업한 뒤, 후속 예제·문서 업로드까지 같은 저장소에서 진행했다. `LLMmanager/linux`의 커밋 [8046594](https://github.com/hy040504/LLMmanager/commit/80465940357cc286db903158352bd89224067092)를 보고했지만 현재 프로젝트의 업로드로 볼 수 없었다. 사용자는 `ai-complaint-process`의 `main`·`ui` 브랜치를 지적했다.

기대 동작은 API 서버의 운영 설정과 이 프로젝트에서 쓰는 호출 예제·문서를 각 저장소에서 관리하고, 요청한 저장소·브랜치의 실제 원격 반영을 확인한 뒤 보고하는 것이다.

## 3. 재현·확인 방법

`git remote -v`, `git branch --show-current`, `git ls-remote --heads origin main ui`로 확인했다. 이 프로젝트의 원격은 `hy040504/ai-complaint-process`, 작업 브랜치는 `main`이며 원격에 `main`·`ui`가 있다. 정정 작업 시작 시 로컬 HEAD와 `origin/main`은 같았다. 기존 미추적 `.config/`는 사용자 작업으로 보존했다.

## 4. 원인 분석 또는 결정 근거

API 운영 저장소로 이동한 뒤 후속 GitHub 업로드 요청의 대상 저장소를 현재 프로젝트와 대조하지 않았다. 브랜치 이름만으로 반영 위치를 보고한 것이 원인이다. 서버의 Caddy·터널 설정은 LLMmanager에서 관리하고, 의존성 없는 Python 클라이언트와 프로젝트 사용 안내를 `ai-complaint-process/main`에 추가하기로 했다.

실제 LLM 추론·모델 적재·검색 회귀·데이터 재적재는 수행하지 않았다. 이 독립 예제는 검색 API·DB·색인과 연결되지 않아 해당 동작을 변경하지 않는다. 모델 품질·판정 임계값·최종 LLM은 확정하지 않았다.

## 7. 완료 조건·후속 작업·복구

예제와 문서 작성·검증을 완료하고 반영 대상을 `ai-complaint-process/main`으로 정정했다. 원격 업로드 완료는 이 사례를 포함한 커밋의 HEAD와 `git ls-remote --heads origin main` 해시 일치로 확인한다. `ui`와 기존 미추적 파일은 변경하지 않는다. 별도 LLMmanager 업로드를 취소하거나 서버를 재시작하지 않는다.

검색·판정·FAQ 답변 통합과 평가의 후속 완료 조건은 [실행 계획](../../plan/harness-roadmap.md)을 따른다. 필요하면 이 사례에서 추가한 예제·문서 변경을 일반 되돌리기 커밋으로 복구하며 실제 API 운영과 DB는 별도다.

### 후속: 로컬 예제 단순화 · 2026-10-30 UTC

사용자가 주소·헤더·기존 토큰 값을 직접 넣고 데이터를 가공하지 않는 단순한 프로그램을 요청했다. 로컬 `scripts/외부_LLM_예제.py`를 단일 POST·응답 본문 출력으로 줄였다. 한국어 주석·변수 타입 힌트는 유지하고 모델 자동 조회·대화 이력·환경변수·별도 오류 처리 함수를 제거했다.

현재 모델명을 읽기 전용으로 조회하고 모의 응답에서 요청 헤더·본문·응답 원문 출력을 확인했다. 실제 생성 호출은 실행하지 않았다. 이 버전은 실제 토큰을 포함하므로 로컬 수정으로 유지했으며 GitHub에는 업로드하지 않았다. 앞선 `main` 반영 기록은 환경변수 방식의 초기 예제에 해당한다.

### 후속: 지정 토큰을 포함한 공유 요청 · 2026-10-30 UTC

사용자가 다른 사람에게 공유하기 위해 토큰을 포함한 GitHub 업로드까지 명시적으로 요청했다. 앞선 로컬 유지 방침을 이 요청에 맞춰 변경하고 단순 예제와 관련 문서를 `ai-complaint-process/main`에 반영한다. 공개 대상은 예제에 직접 적은 지정 토큰이며, 기존 미추적 `.config/`와 다른 비공개 환경 파일은 포함하지 않는다. 실제 생성 호출 없이 앞서 통과한 모의 응답·구문·정적 검사 결과를 사용한다.

2026-10-31 후속: 종합 점검에서 독립 예제의 인증 값을 PUBLIC_LLM_TOKEN 환경변수로 변경했다. 이전 공유 방식은 과거 기록이며 현재 실행은 외부 LLM 안내를 따른다.
