## 2. 배경·증상과 기대 동작

- 관찰한 사실과 영향: CASE-056은 JSON 수신만 하고 검색·판정을 비워 두었다.
- 기대 동작: 코드가 검색 API를 먼저 호출하고, 그 후보로 판정한다. Codex는 PostgreSQL을 직접 쓰지 않는다.
- 확인 근거: 2026-11-06 사용자 요청.

## 3. 재현·확인 방법

- 비교한 기존 동작: 202와 `llm.sent=false`.
- 판단 근거: `run_web_assist`와 같은 파이프라인. 재정렬은 검사기 웹에서 끈다.

## 4. 원인 분석 또는 결정 근거

- `search_complaint_rag`는 PostgreSQL 제품이 아니다. 이 저장소가 만든 MCP 도구이며 검색 API만 호출한다.
- 검색 질의에 분야를 넣지 않는다.
