## 2. 배경·기대 동작

- 기존에는 명령 프롬프트에서 가상환경 Python으로 `-m src`를 직접 실행한 뒤 주소를 브라우저에 입력해야 했다.
- `웹-시작.cmd` 실행 한 번으로 서버를 별도 CMD 창에서 유지하고, 준비 완료 후 기본 브라우저의 `/#/citizen`을 열어야 한다.
- 이미 같은 포트에서 실행 중인 서버는 다시 시작하지 않아야 한다.

이 호스트의 `.venv-web`은 다른 사용자 경로의 Python 3.12를 가리켜 실행되지 않았다. 현재 사용자에 Python 3.12.10을 설치한 뒤 `.venv-web`을 다시 만들고 `src/requirements-dev.txt`를 설치했다.

## 4. 검증 결과와 한계

| 수행일·환경 | 확인 방법·명령 | 실제 결과 | 증거 파일·커밋 |
| --- | --- | --- | --- |
| 2026-11-05 UTC / Windows / Python 3.12.10 `.venv-web` | `pytest rag/tests/test_assist.py src/tests -q -p no:cacheprovider` | 35개 통과 | 로컬 실행 |
| 2026-11-05 UTC / Windows | 서버가 떠 있는 상태에서 `웹-시작.cmd` | 종료 코드 0, 새 `-m src`를 만들지 않음, `http://127.0.0.1:5000/#/citizen` 열기 호출 | `웹-시작.cmd`, `scripts/웹_시작.py` |
| 2026-11-05 UTC / Windows | `GET /api/v1/health`, `GET /` | 200, health JSON `status=ok`, 시민 HTML 1136바이트 | 로컬 서버 |

- 브라우저 자동화 도구가 없어 시민 화면의 클릭·입력 흐름은 확인하지 못했다. 주소 열기 호출과 HTML·health 응답만 확인했다.
- 스크립트는 서버 창을 닫으면 서버가 종료되는 로컬 개발용이다. 운영 서비스·원격 바인딩·공식 행정 이관을 구성하지 않는다.

## 5. 완료 조건·후속 작업·복구

- 요청 범위인 CMD 실행·기본 브라우저 열기·기존 서버 중복 실행 방지는 스크립트에 반영했다.
- 되돌릴 때는 `웹-시작.cmd`, `scripts/웹_시작.py`와 이 문서·색인·변경 이력 항목을 함께 제거한다. 업무 DB와 RAG 원본에는 복구 대상 변경이 없다.
