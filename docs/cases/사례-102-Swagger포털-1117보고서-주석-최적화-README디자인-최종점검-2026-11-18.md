## 2. 점검 배경 및 발견 사항

- 한국어 주석/docstring/JSDoc 점검 결과:
  - `src/complaints/swagger_page.py` 인라인 JS(`readSavedTheme`, `applyTheme`, `resolveInitialTheme`, `refreshStatus`, `updateSession`, `CheongjuSwaggerPlugin`)와 `scripts/reports/daily_report_20261117.py` 내부 HTML 빌더 함수(`_build_page1_main_report_html`, `_build_att1_*`, `_build_att2_*`, `_build_ui_item_card_html`, `main`)에 한국어 JSDoc·Google `Args:`/`Returns:`/`Raises:` docstring이 누락되거나 축약돼 있었습니다.
  - 또한 `swagger_page.py`가 Python `f"""..."""` 문자열을 사용하므로 JS JSDoc 타입 중괄호(`{Promise<void>}`, `{"light"|"dark"}` 등)를 `{{...}}`로 이스케이프하지 않으면 파싱(`Black`)·런타임 `NameError`가 발생할 수 있음을 확인해 즉시 전량 `{{...}}`로 교정했습니다.
- 코드 중복·재계산 최적화 포인트:
  - `swagger_page.py`: `data-session-role` 클릭 핸들러와 `#swg-session-clear` 핸들러에 중복되던 `/api/v1/session` `fetch` + `finally { refreshStatus(); }` 호출을 공용 `updateSession(method, role)` 헬퍼로 통합했습니다.
  - `scripts/reports/daily_report_20261117.py`: `_build_ui_item_card_html` 내 `if item.side_by_side:`와 `else:` 분기에서 반복되던 캡처 HTML 생성 루프를 단일 `capture_blocks` + `layout_class` 경로로 통합했습니다.
  - `ui/src/api-docs.js` · `app.js`: ① `citizen.js`가 이미 export하는 `escapeHTML`을 재사용해 `api-docs.js` 로컬 `e()` 중복 함수를 제거했습니다. ② `summarizeOpenApiSpec(spec)` 시점에 엔드포인트별 소문자 `searchText`를 미리 계산하고, `backendSwaggerPage`·`app.js`(`openApiSummary`)·`renderApiEndpointListHtml(specOrSummary)`가 캐시된 요약을 공유하도록 개선해 렌더 1회당 중복 파싱(2회→0/1회)과 키 입력마다 전체 문자열 결합/소문자 변환을 제거했습니다.
- `#/staff/api` 실시간 Edge CDP 대비 감사 추가 발견·수정:
  - 다크 모드(`body[data-theme="dark"][data-site="staff"]`)의 **엔드포인트 빠른 색인** 표 제목(`.staff-api-table-wrap tbody td:nth-child(4) strong`)이 `staff.css`의 기본 `#0f172a` 명시도에 가려 어두운 배경(`#121c30`) 위에서 대비 **`1.05`**로 거의 보이지 않던 문제를 `#f8fafc`로 교정했습니다.
  - 다크 모드 활성 태그 칩 카운트(`.staff-api-page .staff-filter-chip.active` / `span`)의 흰 글자 대비 `3.49`를 `#1d4ed8` + `rgba(15, 23, 42, 0.35)`로 보완하고, 라이트 모드 `.staff-api-title > span`(`M-05`)과 `.staff-api-page .info-banner.amber` 텍스트 색상을 `#475569`·`#6e4e10`으로 높여 WCAG 4.5+를 맞췄습니다.
- README 디자인·문서 정합:
  - `README.md` 상단 배지가 3행(11개)에 편중되던 구성을 **3행(7·8·8개)** 테마별 그룹으로 균형 재배치하고 `Swagger-:5000 /docs · #/staff/api` 배지·네비게이션 링크·`[!NOTE]` Swagger 요약 및 `CASE-101`·`CASE-102` 검증 근거를 반영했습니다. (`11/17` 보고서 본문 및 `UI_수정_보고_2026-11-17.pdf` 원문 내용은 일절 변경하지 않았습니다.)
