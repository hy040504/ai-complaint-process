## 1. 요청

담당자 페이지 맨 위의 **"담당자 콘솔 / 응대 검사기" 전환 띠**를 없애 담당자 사이트가 단독 사이트로 보이게 하고(목업 느낌 제거), 응대 검사기는 **별도 경로**로 분리한다.

## 2. 변경

| 대상 | 전 | 후 |
| --- | --- | --- |
| 담당자 화면 맨 위 | 검은 띠: `DEMO` 표시, "합성 데이터로 체험하는 업무 콘솔" 문구, **담당자 콘솔 / 응대 검사기** 전환 | **띠 전체 삭제.** 사이드바·상단바가 화면 맨 위부터 시작 |
| 담당자 문구 | 사이드바 "담당자 콘솔", 상단 "로컬 시연", 아래쪽 "7테이블 정규화 · Swagger API" | "담당자", "데모 계정"(로그인 계정이 시연용일 때) 또는 "인증 세션", "공식 접수·외부 이관은 연동되어 있지 않습니다" |
| 응대 검사기 | 담당자 사이트의 `#/lab` 해시 화면 | **`/lab/` 단독 페이지**(`ui/lab.html`). 어느 화면에도 링크 없음. `/lab`은 `/lab/`으로 308 이동 |
| 담당자 사이트의 `#/lab` | 검사기 화면 | 담당자 홈으로 되돌림 |

- 서버: `src/complaints/pages.py`에 `/lab`, `/lab/` 경로 추가(접근 제한은 CASE-129).
- 프런트: `site.js`에 `lab` 사이트 종류 추가(`/lab`만 허용). 담당자 셸(`staff.js`)에서 띠와 역할 전환 삭제, 담당자 CSS에서 띠 높이(36px·34px)를 기준으로 하던 위치 값을 0으로 정리(사이드바·상단바·빠른 메뉴·최소 높이).
- 담당자 화면이 쓰던 `lab.css`는 담당자 페이지에서 빼고 `lab.html`에서만 불러온다.

## 3. 같이 고친 것

- **가이드 담당자 그림 재촬영:** 띠가 사라져 번호 위치가 어긋나므로 좌표를 36px 올려 다시 찍었다(`s01`~`s08` 10장).
- **가이드 모달 번호 누락(기존 결함):** 로그인·부서 배정·미리보기·게시판 내리기 창과 시민 로그인 창(`c02`)의 번호 표시가 그림에 처음부터 보이지 않았다. 열린 모달은 브라우저 최상위 층에 그려져 `body` 위의 표시를 가리기 때문이다. 촬영 도구가 열린 모달 안에 표시를 그리도록 고쳐 다시 찍었고, 부서 배정 창(AI 추천 부서 후보 줄이 늘어난 모양)의 좌표도 맞췄다. 글의 번호와 그림의 번호가 이제 일치한다.
- 촬영 중 로컬 DB에 생긴 시험 민원 1건은 삭제했다(남은 민원 수는 촬영 전과 같다).
