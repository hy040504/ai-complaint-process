## 2. 배경·증상과 기대 동작

- 관찰한 사실과 영향: 패키지 분리 직후 일부 함수 docstring이 한 줄 요약만 있고, 문서가 옛 `src/api.py`·검증 건수를 가리켰다.
- 기대 동작 또는 요구사항: 인자가 있는 함수는 Google 형식 `Args`/`Returns`/`Raises`를 맞추고, 현재 패키지 경계를 문서에 적는다.
- 확인 근거와 시점: 2026-11-05 사용자 요청.

## 3. 재현·확인 방법

- 비교한 기존 동작: [주석 규칙](../harness/코드_작성과_주석_규칙.md)의 Google 형식과 CASE-026 직후 파일.
- 판단 근거: 역사 사례(CASE-022·023)의 당시 경로는 그대로 두고, 현재 기준 문서만 고친다.

## 4. 원인 분석 또는 결정 근거

- 확인된 원인·근거: 분리 때 함수를 옮기며 한 줄 요약을 유지한 항목이 있었다.
