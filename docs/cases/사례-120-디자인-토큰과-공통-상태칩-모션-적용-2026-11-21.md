## 1. 배경

시민·담당자 화면이 어색하고 정적이라는 지적에 따라 CSS를 측정하고 디자인 시안(Design 캔버스)을 만들어 방향을 정한 뒤 코드에 적용했다. 시안의 순서는 ① 토큰 ② 블록 공통화 ③ 모션 ④ 다크 변수화 ⑤ 검증이다.

## 2. 측정으로 확인한 문제

| 항목 | 적용 전 | 비고 |
| --- | --- | --- |
| 브랜드색 | `:root` 토큰은 청록(`#087F72`), 실제 화면은 파랑(`#2F6FED`, 시민 CSS 42회). 다크는 `--teal`을 파랑으로 덮어써 **라이트와 다크의 브랜드색이 달랐음** | `theme-color` 메타도 청록 |

## 4. 겪은 문제와 수정

- **다크 테마 회귀(제 실수):** 정리 스크립트가 선택자 목록을 쉼표로 단순 분리해 `:is([data-site="citizen"], [data-site="lab"])` 안의 쉼표에서 잘렸다. 괄호가 열린 채 남은 선택자 때문에 브라우저가 뒤의 다크 규칙까지 삼켜 **다크 게시판의 표 머리줄이 흰색, 제목이 어두운색**이 되었다. 스크린샷 전후 비교로 발견해 CSS 5개를 되돌리고 괄호 깊이를 고려한 분리로 다시 적용했다. 재발 방지로 `css-integrity.test.mjs`(괄호 균형·선택자 괄호 검사)를 추가했다.
- 새 행 플래시가 처음에는 재렌더로 사라져 동작하지 않았다. 시작 시각을 기억하도록 고치고 브라우저에서 약 2.7초 지속(중간 재렌더 포함)을 확인했다.
- 측정 중 만든 시험 민원 3건이 로컬 DB에 남아 정리했다(서버에는 영향 없음).

## 5-1. 후속 조치 (같은 날)

- **모서리 4단계화(구현):** 5개 CSS의 `border-radius` 164개 선언(다중·개별 모서리 포함)을 6/10/16/999 토큰으로 바꿨다. 고유 값 21종→4종, px 직접 값 0. 값이 달라지는 곳(예: 13~15px→16px)은 있으나 레이아웃은 그대로다.
- **다크 변수화(구현):** `themes.css`의 다크 범위 색 선언 911개를 역할별 대표색 190개(`--d-bg/text/line-NN`, `tokens.css`)로 묶어 `var()`로 교체했다. 허용 오차는 채널당 6/255라 색이 최대 6 달라질 수 있다. 직접 hex는 40개(그라디언트·그림자 등 범위 밖) 남았다.
- **사이드바 활성 막대(구현):** CSS `::before`만으로 활성 항목 왼쪽에 파란 막대가 자라나게 했다(동작 줄이기에서 정지).
- **검증:** 라이트 6화면은 반영 전과 픽셀 완전 일치. 다크 6화면은 최대 채널차 17~23, 6 초과 픽셀은 화면당 0.1~0.5%로 사이드바 글자 가장자리에 몰려 있고 육안상 이상 없음. `ui test` 59 pass(px 모서리 금지·다크 토큰 정의 테스트 추가).

## 5-2. 블록 공통화 (같은 날)

- **타입 스케일(구현):** `--ty-title` 28/24px, `--ty-section` 15/14px, `--ty-sub` 12/11px, `--ty-eyebrow` 11/10px(모바일 기준 700px)를 `:root`에 두고 `design.css`에서만 적용한다. 적용 전 페이지 제목은 23~29px 8종, 섹션 제목은 12~15px 4종이었다. 기존 CSS의 해당 선택자 글자 규격 선언 50개를 삭제해 단일 출처로 만들었다.
- **카드 그림자·행 호버(구현):** 시민 게시판 카드·상태 카드·API 통계 카드의 그림자를 `--e1`로, 시민 알림·통계 막대 행의 호버 배경을 `--cj-row-hover`로 통일했다.
- **겪은 문제:** 토큰을 파일 중간 지점에 삽입하다 다크 전용 블록(`body[data-theme="dark"]`)에 들어가 라이트에서 `var(--ty-title)`이 비어 시민 제목이 작아졌다. 스크린샷에서 발견해 `:root`로 옮기고 `:root` 정의 테스트를 추가했다.
- **검증:** `ui test` 61 pass(글자 규격 단일 출처·토큰 위치 테스트 추가), 담당자 3화면 계산값이 데스크톱 28/15/11px·600px 24/14/10px로 일관, 라이트·다크 스크린샷 확인.
