## 2. 배경·증상과 기대 동작

- 관찰한 사실과 영향: 기존 `/#/lab`는 시민·담당자 SPA에 붙어 있고, assist API는 `query` 한 줄만 받는다.
- 기대 동작: 검사기만 있는 화면에서 제목·분야·지역·상세 내용을 JSON으로 보내고, 서버가 언어 모델에 넘기기 위해 그 JSON을 받는다.
- 확인 근거와 시점: 2026-11-06 사용자 요청. GitHub 기본 브랜치를 `llm`으로 전환.

## 3. 재현·확인 방법

- 비교한 기존 동작: `python -m src`가 UI 전체와 CRUD를 제공한다.
- 판단 근거: 검사기 웹은 별도 포트로 두어 `:5000` 업무 서버를 끄지 않는다.

## 4. 원인 분석 또는 결정 근거

- 확인된 원인·근거: 1차 경로는 프론트 추출과 수신 API다. 모델 호출은 다음 작업이다.
- 검토한 선택지와 결정 이유: 새 Flask 앱 `src.lab_web`. 업무 PostgreSQL과 검색 색인을 쓰지 않는다.
