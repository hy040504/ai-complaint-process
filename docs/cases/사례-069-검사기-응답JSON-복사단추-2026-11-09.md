## 2. 배경·증상과 기대 동작

- 관찰한 사실과 영향: 응대 결과는 Codex 입력·보낸 민원·받은 응답 JSON을 `<pre>`로만 보여 주어 손으로 골라 복사해야 했다.
- 기대 동작 또는 요구사항: 각 JSON 칸 옆에 복사 단추가 있고, 누르면 그 칸 본문만 클립보드에 넣는다.
- 확인 근거와 시점: 2026-11-09 사용자 요청 「민원 응답으로 나온 json들을 각각 복사할수잇는 버튼들」.

## 3. 재현·확인 방법

- 재현 환경·선행 조건: `http://127.0.0.1:5010/`에서 민원을 보내거나 오른쪽 테스트 기록을 고른다.
- 단계: `Codex에 보낸 데이터`, `검사기에 보낸 JSON`, `검사기가 받은 JSON`의 `JSON 복사`를 각각 누른다. 단추 문구가 잠시 `복사됨`으로 바뀐다.
- 비교한 기존 동작: JSON은 결과 칸에만 있었고 복사 단추는 없었다.

## 4. 원인 분석 또는 결정 근거

- 확인된 원인·근거: 결과 JSON이 세 칸으로 나뉘어 있으므로 단추도 칸마다 둔다.
- 검토한 선택지와 결정 이유: Codex 호출 배열을 항목마다 쪼개지 않고, 화면에 이미 있는 세 JSON 칸을 복사 대상으로 한다. Clipboard API가 없으면 숨은 textarea로 복사한다.
