## 1. 배경

시민·담당자·검사기를 밝은·어두운 테마, 데스크톱·휴대폰(390px)으로 14화면 찍어 점검했다. 가로 넘침과 어두운 테마 대비 문제는 없었고, 고칠 점 7가지를 찾았다. 그중 2~7번을 반영했다. 1번(비로그인 방문자에게 민원 게시판이 막힘)은 서버의 목록 API를 바꿔야 해서 이번에는 하지 않았다.

## 3. 같이 바꾼 것

- **사용 가이드 그림 전부 재촬영(26장):** 담당자 사이드바·시민 문구가 바뀌어 그림을 다시 찍었다. AI 작업 모니터 그림은 좌표 대신 카드 안 요소를 가리키게 바꿔(데이터가 바뀌어도 번호가 맞도록), 배정 해제 그림은 "부서 변경" 버튼을 찾아 누르게 바꿨다. 가이드 글은 "실시간 연결됨" 표기만 고쳤다.
- **README 화면 그림 8장 재촬영:** 이전 그림에는 CASE-128에서 없앤 위쪽 띠(DEMO·담당자 콘솔·응대 검사기)와 "MINWON DESK"·"M-02"가 남아 있었다. 같은 크기(1280×900, 휴대폰 780×1688)로 다시 찍었다.
- 촬영용 시험 민원 2건은 찍은 뒤 삭제했다.
