## 2. 배경·증상과 기대 동작

- 관찰한 사실과 영향: 실행 의존성이 한국어 Ubuntu 스크립트와 Windows 수동 준비에 흩어져 있어 새 환경에서 한 번에 받기 어렵다.
- 기대 동작 또는 요구사항: `setup.cmd`와 Linux `setup.sh`로 DB 프로그램·라이브러리·모델을 받고, 기존 실행기의 Linux bash 버전을 영어 파일명으로 둔다.
- 확인 근거와 시점: 2026-11-06 사용자 요청.

## 3. 재현·확인 방법

- 비교한 기존 동작: Ubuntu는 `검색파이썬_준비.sh`·`검색DB_준비.sh`, Windows는 CASE-036 휴대 zip과 `검색-시작.cmd`.
- 판단 근거: 공통 설치는 `scripts/setup_env.py`가 맡고, OS 래퍼만 나눈다. 이미 있는 가상환경·클러스터·모델 캐시는 지우지 않는다.

## 4. 원인 분석 또는 결정 근거

- 확인된 원인·근거: 루트 실행기는 Windows CMD뿐이고, Linux 사용자는 한국어 스크립트 경로를 직접 알아야 했다.
- 검토한 선택지와 결정 이유: Docker는 쓰지 않는다. Linux 파일 이름은 영어로 두고 한국어 `.sh`는 유지한다. setup은 ingest를 자동 실행하지 않는다.

## 7. 완료 조건·후속 작업·복구

- 완료: 이 Windows 호스트에서 `--check`와 `setup.cmd` 본실행이 기존 설치를 유지한 채 통과했다.
