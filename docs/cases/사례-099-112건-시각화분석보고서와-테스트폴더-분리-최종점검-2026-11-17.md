## 2. 배경·증상과 기대 동작

- 관찰한 사실과 영향:
  - `CASE-097` 시점에는 112건 실측 요약과 3대 한계만 사례 본문에 기록되어 있었고, 112건 전수 결과·시각화 그래프·원자료 JSON은 로컬 임시 스크래치 파일에만 존재했습니다.
  - 일자별 업무보고 PDF 전용 폴더([`docs/report/`](../report/README.md))와 민원 테스트/실증 분석 보고서 폴더를 분리해 관리할 필요가 있었습니다.
  - 신규 생성 스크립트 두 종(`daily_report_20261116.py`, `analysis_report_112.py`) 사이에 헤드리스 브라우저 PDF 인쇄 코드와 Markdown/HTML 표 행 조립 코드가 중복되어 있었습니다.
- 기대 동작:
  - 외부 라이브러리(`matplotlib` 등) 추가 설치 없이 Python 표준 라이브러리만으로 100% 실측 JSON 기반 벡터 차트 4종·Markdown·6쪽 PDF를 재생성할 수 있어야 합니다.
  - 업무보고는 `docs/report/`, 민원 테스트 분석 보고서는 `docs/test/`에 명확히 분리되며 모든 문서 링크·배지·사례 색인이 깨짐 없이 연결되어야 합니다.
