## 2. 배경·증상과 기대 동작

- 관찰한 사실과 영향: `main`은 시민·담당자 CRUD와 검사기가 한 UI에 있다. 지금부터는 검사기에서 민원을 보내 RAG+LLM 응답을 받는 1차 경로만 집중한다.
- 기대 동작 또는 요구사항: GitHub에 `llm` 브랜치를 만들고, `http://127.0.0.1:5000/#/lab`가 기본 화면이다. 빈 해시와 `/#/citizen`·`/#/staff`는 검사기로 보낸다.
- 확인 근거와 시점: 2026-11-06 사용자 요청.

## 3. 재현·확인 방법

- 비교한 기존 동작: `웹-시작.cmd`와 빈 해시는 `/#/citizen`을 열었다. 검사기 헤더에 시민·담당자 전환이 있었다.
- 판단 근거: 시민·담당자 코드를 지우면 `main` 병합이 어려워진다. 이 브랜치에서는 화면만 검사기로 고정한다.

## 4. 원인 분석 또는 결정 근거

- 확인된 원인·근거: 응대 경로(`POST /api/v1/assist`, `src.assist`, `/#/lab`)는 이미 있다. 부족한 것은 브랜치 경계와 기본 진입점이다.
- 검토한 선택지와 결정 이유: CRUD API는 Flask에 남긴다. UI 해시는 검사기만 연다. LLM 공급자·키는 `.env`를 바꾸지 않는다.
