## 2. 배경·증상과 기대 동작

- 관찰한 사실과 영향: 보류 3건을 `codex_cli`로 돌렸고 갈래는 3/3이다. 실행기가 기본 경로 `assist-eval-draft.json`을 쓰면 개발셋 26/26을 덮는다. `--output` 주석과 README 배지가 보류 실측 이전 상태였다.
- 기대 동작 또는 요구사항: 한국어 Google 형식 docstring, 보류 보고를 개발셋과 나누고, 현재 문서는 3/3을 적는다. 이 점수로 PREFIX를 고치지 않는다.
- 확인 근거와 시점: 2026-11-07 사용자 요청 「주석 점검, readme/docs 업데이트, readme 디자인 개선, 코드 최적화, 깃헙 업로드」.

## 3. 재현·확인 방법

- 비교한 기존 동작: `--output` 상대 경로를 `main`에서 직접 붙였다. `--only`/`--missing` 필터를 `select_items`와 따로 썼다. README Eval 배지는 초안 29만 보였다.
- 판단 근거: `resolve_report_path`와 `HOLDOUT_REPORT_PATH`로 경로를 맞춘다. 문항 고르기는 `select_items` 한 경로다.

## 4. 원인 분석 또는 결정 근거

- 확인된 원인·근거: 보류 실측은 동작 기록에 집중했고 주석·현재 문서·소규모 정리를 이 작업으로 넘겼다.
- 검토한 선택지와 결정 이유: 보류 점수로 PREFIX를 고치지 않는다. 400문항으로 표시하지 않는다. `.env`는 Git에 넣지 않는다.
