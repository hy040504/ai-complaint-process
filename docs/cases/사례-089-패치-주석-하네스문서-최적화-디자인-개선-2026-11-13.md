## 2. 배경·증상과 기대 동작

- 관찰한 사실과 영향:
  - 최근 [CASE-083](사례-083-서원대후문-장소추적-MCP연동-위치인식-2026-11-13.md)~[CASE-088](사례-088-EXAONE-429-재시도와-스트림-오류-전체점검-2026-11-13.md) 패치 과정에서 변경된 일부 함수(`pipeline.py`의 `chat`, `app.py`의 `_finish_run`/`generate`, `complete.py`의 `_as_int`, `ui/tests/lab.test.mjs` 도우미)의 Google `Args:`/`Returns:`/`Yields:` 및 JSDoc 주석이 비어 있었고, `test_place_tool.py`의 미사용 import와 `models.py`의 중복 공백 정규화 검증기가 남아 있었습니다.
  - `src/llm/complete.py`의 `_as_int`와 `usage_from_openai`는 `bool` 값(`isinstance(value, bool)`) 배제와 `0` 토큰(`falsy`) fallback 처리가 빠져 있었습니다.
  - 하네스 문서 4종(`AI_안전_보안_가드레일.md`, `AI_정보전달과_응답_하네스.md`, `architecture.md`, `시스템_프롬프트와_프리픽스_캐싱_지침.md`)과 `README.md` 일부 항목에 `exaone_api`(`K-EXAONE 2.5`), `lookup_navermap_place` MCP, `inferred_place`, `PREFIX-03`/`04` 상태, 429 백오프·연쇄 차단(`CASE-088`) 내용이 누락되어 있었습니다.
- 기대 동작 또는 요구사항:
  - 모든 수정 파일이 [코드 작성·주석 규칙](../harness/코드_작성과_주석_규칙.md)을 충족하고, 문서와 실제 코드 계약을 일치시키며, 상시 `:5010` 검사기 웹도 최신 코드로 동작해야 합니다.

## 3. 확인 방법과 점검 항목

- Python AST 스캔(`4b09a80^..HEAD` 및 작업 트리 16개 `.py`·4개 `.js`/`.mjs`)으로 비한국어 docstring, `Args:`/`Returns:`/`Yields:` 누락, 미사용 import를 전수 검사했습니다.
- `docs/harness/*.md`를 실제 `src/llm/`, `src/assist/`, `src/rag/http.py` 구현과 대조했습니다.

## 4. 원인 분석 및 최적화·문서 정비 근거

- `src/lab_web/models.py`: `blank_district_to_none`과 `blank_provider_to_none`이 동일 로직을 반복하고 있어 Pydantic `ValidationInfo`를 쓰는 단일 `@field_validator("district", "provider", mode="before")` `blank_optional_to_none`으로 통합했습니다.
- `src/llm/complete.py`: Python에서 `bool`이 `int`의 하위 클래스이므로 `_as_int`에 `not isinstance(value, bool)` 조건을 명시하고, `input_tokens`/`output_tokens` 조회에 `_first_int()`를 분리해 `0` 토큰이 `None` 취급되어 대체 키로 넘어가는 경계 오류를 제거했습니다.
- `README.md`: 상단 배지 18개를 역할·문서·검증 3개 주제 그룹(`5 + 5 + 6`)과 빠른 탐색 바로 재배치하고, Mermaid `E1` 노드(`429 백오프`)·`EXAONE_URL`/`EXAONE_MODEL` 표·`> [!TIP]` 429 대응 안내·검증 근거 수치를 최신화했습니다.
