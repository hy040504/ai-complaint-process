## 3. 점검 중 확인한 보완 사항

1. **주석·docstring 누락:** `src/complaints/service.py` 내부 프로토콜·헬퍼(`AssistIterFn.__call__`, `_ai_district_arg`, `apply_checked`, `_matches_running_job`, `_commit_ai_completion.update`, `_commit_ai_failure.update`)에 Google 형식 `Args:`/`Returns:` 블록이 비어 있었고, `ui/src/staff.js`의 `listRows` JSDoc에 `mine` 매개변수가 빠져 있었습니다.
2. **런타임·프론트엔드 불필요 비용:**
   - `departments.py`가 매 요청마다 `:8007/departments` HTTP 호출을 반복했습니다.
   - `repository.py`의 `_insert_default_template_rows()`가 루프 안에서 지연 import 및 더미 Pydantic `Complaint` 검증 비용을 치렀습니다.
   - `service.py` `change()`에 `_require_staff()`와 동일한 세션 검사 분기가 중복돼 있었습니다.
   - `ui/src/app.js`가 담당자 화면을 열 때마다 부서·템플릿 목록을 매번 재요청했습니다.
3. **문서 정합·디자인:** `README.md` 하단(`현재 구현 상태`·`응대 검사기`·`저장과 검색`·`검증 근거`)과 `docs/harness/업무DB_실행설계.md`에 신규 `answer_templates`·`app_meta` 테이블, 영구 삭제(`POST /complaints/{id}/delete`), 테스트용/담당자용 부서 메타 분리 설명이 누락돼 있었습니다.
