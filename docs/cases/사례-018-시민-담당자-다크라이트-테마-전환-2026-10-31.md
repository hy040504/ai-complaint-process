두 사이트 상단에 접근 가능한 해·달 테마 버튼을 두고 선택을 `localStorage`의 전용 테마 키에 저장한다. 사이트를 바꾸거나 페이지를 새로고침해도 설정을 불러온다. 다크 모드 색상을 시민 카드·목록·상담·입력·바텀시트와 담당자 메뉴·업무 큐·검토 카드·답변 편집기에 맞췄다. 청주시 로고는 원본 색상을 유지하며 어두운 배경에 흰색 바탕을 적용한다.

## 검증과 한계

Chrome DevTools MCP에서 시민·담당자 두 화면의 버튼을 확인하고 실제 전환·새로고침 후 유지·다른 사이트 이동을 확인했다. PC·모바일 다크 스크린샷과 콘솔을 검사했다. 테마 설정은 UI 표시용 브라우저 설정이며 업무 API나 민원 DB에는 쓰지 않는다. 문법 검사와 기존 API 클라이언트 검증을 통과했다. 작업은 로컬이며 원격 배포하지 않았다.
