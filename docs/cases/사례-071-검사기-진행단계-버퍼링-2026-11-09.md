## 2. 배경·증상과 기대 동작

- 관찰한 사실과 영향: Codex 호출이 길어도 단추만 비활성되어 진행이 멈춘 것처럼 보였다.
- 기대 동작 또는 요구사항: 검색·판정·안내/초안 단계 문구와 대기 애니메이션을 보여 준다.
- 확인 근거와 시점: 2026-11-09 사용자 요청 「버퍼링 효과」, 선택 「진행 단계 표시」.

## 3. 재현·확인 방법

- 재현 환경·선행 조건: `http://127.0.0.1:5010/`에서 민원을 보낸다.
- 단계: 보내기 직후 진행 칸이 열리고 `민원 내용을 읽고 있어요`부터 단계가 바뀐다. 끝나면 결과 칸으로 넘어간다.
- 비교한 기존 동작: 차단 POST만 있어 단계 안내가 없었다.

## 4. 원인 분석 또는 결정 근거

- 확인된 원인·근거: `iter_assist`가 이미 `PROGRESS_LABELS` 진행 사건을 낸다. CRUD Flask의 `/assist/stream`과 같다.
- 검토한 선택지와 결정 이유: 검사기 전용 `/lab/complaints/stream` NDJSON을 두고, 화면은 스트림을 우선하며 실패 시 기존 POST로 넘긴다.
