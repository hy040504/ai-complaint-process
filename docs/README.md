현재 PostgreSQL에는 관계형 데이터와 5,109개 임베딩이 함께 적재되어 있습니다. 부서 디렉터리도 존재하지만 공식 업무분장·관할 보완은 남아 있습니다. **초기에는 LLM + RAG를 연결하고 Jev는 추후 추가**합니다. LLM 판정·자연어 답변·CLI 챗봇과 웹·민원 업무 서버는 아직 미구현입니다. 시연 웹은 게시판·작성 페이지와 민원을 주고받는 서버까지 포함하며, 청주시 공식 접수·외부 이관 연계는 별도 범위입니다.

## 문서 관리

- 프로젝트 목적·현재 상태는 루트 README, 필드 정의는 데이터 사전, 실행 명령은 RAG 문서를 기준으로 유지합니다.
- 설계가 구현되면 상태 표현과 검증 근거를 함께 갱신합니다. 제안을 구현 완료로 표시하지 않습니다.
- 기능·데이터·계약·운영 방식의 의미 있는 변경은 [CHANGELOG](../CHANGELOG.md)에 정리합니다. 문서 간 같은 내용을 길게 복제하기보다 상세 문서로 연결합니다.
- 개별 버그·개선·설계·운영 기록은 [사례 관리 규칙](cases/README.md)에 따라 번호와 한국어 파일명으로 작성합니다. 경위·증거는 사례에, 현재 적용할 기준은 하네스·데이터·실행 문서에 기록하고 서로 연결합니다.
- `.env`, 실제 DB·모델 캐시, 쿠키가 포함된 SAZ는 문서나 Git에 포함하지 않습니다.
